# double_battles (release mirror)

Installable releases of the **Double Battles** mod for [gen1recomp](https://github.com/bryanthaboi/gen1recomp).

Grab the newest `.zip` from [Releases](https://github.com/shanehudson-gen1recomp-mods/double_battles/releases) and install it in-game: **MODS > Import mod .zip**. Installed copies get update checks through the launcher automatically.

Source code and issues live in the [mods monorepo](https://github.com/shanehudson-gen1recomp-mods/gen1recomp-mods); this repo only hosts releases.

## All mods in this family

- **Double Battles** (`double_battles`, this repo)
- [Free Fly](https://github.com/shanehudson-gen1recomp-mods/free_fly) (`free_fly`)
- [Wild Skies](https://github.com/shanehudson-gen1recomp-mods/wild_skies) (`wild_skies`)
